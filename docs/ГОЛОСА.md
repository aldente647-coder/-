# Варианты озвучки

Подача, выбранная владельцем 08.09.2026: спокойная и доброжелательная.

Пять вариантов Silero: Бая (`baya`), Ксения (`kseniya`), Ксения X (`xenia`),
Айдар (`aidar`), Евгений (`eugene`). Для сравнения используется `/voices`:
четыре одинаковые реплики каждого голоса в 8 и 24 кГц. Телефонный пример
совпадает с файлом демо. Ссылка `/demo?voice=…` открывает анкету выбранным голосом.
Обычный `/demo` продолжает использовать действующую библиотеку.

## Как сделаны записи

- Модель `v5_5_ru`, CPU, локальный файл; тексты опроса не отправляются в облачный TTS.
- Ударения и «ё» расставляет модель. Вопросительная интонация определяется моделью.
- SSML добавляет паузу 250 мс между предложениями, не меняя темп или высоту голоса.
- В произносимом тексте Max и Telegram передаются как «Макс» и «Телеграм»;
  исходная анкета и контрольный хеш текста сохраняются. Это также обходит ошибку
  модели v5_5_ru при разборе латиницы внутри SSML.
- Записи фиксируются в WAV, PCM16, mono. Частота телефонной библиотеки — 8 кГц.
  24 кГц доступны только для сравнения тембра: телефонная линия сужает полосу.
- `voice.json` хранит идентификатор модели, SHA-256 файла весов и редакцию обработки
  текста в `synthesis_id`. При их изменении кэш озвучки не переиспользуется.

Модель: https://models.silero.ai/models/tts/ru/v5_5_ru.pt
SHA-256: `50081637b602126ee06cb3bc8a744d25651d2da149ee8864b9a379bfdd934437`.

Документация: [Silero](https://github.com/snakers4/silero-models#v5),
[SSML](https://github.com/snakers4/silero-models/wiki/SSML).

## Повторная сборка

На сервере файл модели лежит в `/opt/socmon/models/v5_5_ru.pt`.
Сборку выполнять от `socmon`, в отдельный каталог; после проверки готовности
перенести каталог под `SOCMON_MEDIA_DIR/voices` и перезапустить кабинет.

```bash
/opt/socmon/venv/bin/python -m socmon voice variants \
  --model-path /opt/socmon/models/v5_5_ru.pt \
  --out /opt/socmon/voice-build-next/voices
```

Для отдельной анкеты:

```bash
socmon voice render src/socmon/questionnaires/wave-base.yaml \
  --voice baya --model-id v5_5_ru \
  --model-path /opt/socmon/models/v5_5_ru.pt --natural --out /tmp/voice-baya
```

Актуальные `wave-*.yaml` используют общие формулировки и собираются совместно.
Историческую `core-v1.yaml` следует озвучивать в отдельный каталог: ряд её ключей
совпадает с актуальными, а тексты отличаются. Сборщик вариантов отклоняет
различающиеся формулировки под одним audio_key до записи файлов.

## Оценка качества

Наличие пауз и новая модель не доказывают, что голос звучит как человек.
Выбирать вариант нужно прослушиванием. Сравнивайте прежде всего 8 кГц:
разборчивость, ударения, мелодику вопросов, отсутствие усталости на длинных
репликах. Затем проверьте выбранный голос на настоящем телефонном канале.
На странице доступны только синтезированные голоса; это сообщается во вступлении.

## Анна и Алексей: Qwen3-TTS

Добавлены два синтетических тембра со спокойной доброжелательной подачей:
`anna` (Анна) и `alex` (Алексей). Референсы созданы VoiceDesign по описанию;
записи реальных людей не использовались. Base-модель сохраняет тембр референса
в каждом вопросе. Интонацию определяют пунктуация текста и подача референса.
Слова, варианты ответа и граф переходов сохраняются из YAML.

- Генерация выполняется заранее на Apple Silicon, локально через MLX.
  Первые записи собраны версией 0.3.1 (это сохранено в манифестах);
  окружение дальнейшей сборки обновлено до `mlx-audio==0.5.3` и `transformers==5.16.1`.
  На сервер передаются готовые WAV; нейросеть в звонке не запускается.
- Мастер 24 кГц: фильтр 45 Гц удаляет DC/низкочастотный гул, нормализация
  выравнивает уровень с запасом до перегруза. Удаляются только внешние пустые
  края с запасом 80 мс, внутренние паузы остаются. Короткие плавные края
  и защитная тишина предотвращают щелчки при запуске/остановке файла.
- Телефонный PCM16 mono 8 кГц получается из того же мастера полифазной
  передискретизацией с антиалиасингом. Темп и высота голоса не меняются.
- Мастера кэшируются по модели, референсам, голосу и точному тексту.
  Отдельный `voice.json` для каждой библиотеки защищает от устаревших формулировок.
- Анкета из базы хранится отдельно от актуальных `wave-*.yaml`: одинаковые
  audio_key в разных редакциях не должны перезаписывать друг друга.

Модели и фиксированные ревизии:

- [VoiceDesign 4-bit](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-VoiceDesign-4bit),
  `5c390979e4b93af5f2932f90742ca99c7dd04687`.
- [Base 4-bit](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-Base-4bit),
  `37e955a1deb861c088ae5f3a67043185f3d1a60c`.
- [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS),
  [MLX Audio](https://github.com/Blaizzy/mlx-audio/blob/main/docs/guides/voice-cloning.md).

Повторная сборка на Mac (пути указываются к локальным моделям и референсам):

```bash
uv sync --extra voice-mlx
uv run socmon voice realistic --out /tmp/new-voices \
  --model-path /path/to/Qwen3-TTS-Base-4bit \
  --references /path/to/references --cache /path/to/master-cache
```

В каталоге референсов должны быть `anna.wav`, `anna.txt`, `alex.wav`, `alex.txt`.
Для вновь загруженного YAML передайте его путь после `realistic` и отдельный
`--out`. Затем выполните `socmon voice check анкета.yaml --media каталог/anna`
(аналогично для `alex`). Автоматическая озвучка при загрузке в кабинет пока
не подключена: новую редакцию нужно собрать и проверить перед использованием.

Для звонка выбор библиотеки задаётся существующим аргументом
`calltest --media /opt/socmon/media/voices/alex` или `.../anna`.
Для анкеты из базы используется её отдельный каталог и соответствующий YAML.

Кабинет проверяет готовность озвучки по каталогу
`/opt/socmon/media/questionnaires/<хеш содержимого YAML>/anna`, если он существует,
затем — по общей библиотеке. `calltest --voice anna` / `--voice alex` выбирает
соответствующую запись этой редакции. Если её нет, проверка полноты блокирует
несовместимую озвучку. Загруженная на стенде анкета имеет вычисляемый хеш
`6ebc22afcabaaf60`; её библиотека отделена от текущей базовой волны.

Проверка распознаванием обязательна для новых записей Qwen: модель может
повторить слово или ошибиться в произношении. Для отдельных дублей поддержан
`--retakes retakes.json`: словарь `"голос:хеш_текста": номер_дубля`.
Вся карта учитывается в манифесте, неизменившиеся мастера сохраняются.
После повторной сборки нужно повторить проверку изменившихся файлов.

## Подача — 09.09.2026

Робота выдаёт не тембр, а поведение: следующий вопрос вылетает в ту же
миллисекунду, как распознан ответ; между вопросами ни «угу», ни паузы;
переспрос — тот же файл слово в слово; каждый звонок звучит как предыдущий.
Слой подачи (`socmon/voice/delivery.py`) решает ровно это, не трогая
ни граф анкеты, ни формулировки вопросов.

**Служебные реплики** — `socmon/voice/delivery.yaml`: отклики после
закрытого ответа («угу», «понятно», «ясно»), после развёрнутого («спасибо,
понятно»), после отказа («хорошо», «понимаю»), префиксы переспроса («простите,
я не расслышала, повторю вопрос» / «конечно»), оклик в тишину («алло, вы меня
слышите?»). Формы рода заданы парой. Каталог подлежит утверждению Заказчиком
наравне с анкетой и версионируется хешем, как она.

**Правила.** После закрытого ответа отклик звучит примерно в половине случаев
и никогда дважды подряд одним словом. После открытого — всегда. После согласия
и фильтров — никогда. Паузы случайные в человеческих пределах: 250–500 мс
перед откликом, 200–450 после, 350–700 перед вопросом без отклика, 500–900
после развёрнутого ответа. В тишину оклик через 3,5 с, повтор вопроса — через 6.
Все решения принимает генератор случайности с зерном из идентификатора
звонка: подача любого звонка воспроизводима.

**Дубли.** Каждая реплика синтезируется трижды при температуре 0,8; лучший
по просодии — темп, движение высоты голоса, отсутствие провалов и перегруза —
становится основным (`key.wav`), остальные лежат рядом (`key-t2.wav`,
`key-t3.wav`). Подача выбирает дубль на каждый звонок, поэтому два звонка
не звучат одинаково. Дубли чуть отличаются громкостью, как у живого человека.

**Речевая разметка** (`socmon/voice/spoken.py`) — формулировка в том виде,
в каком её произносят: перечисление вариантов через точку с запятой читается
как отдельные фразы с паузами, перед «или» — пауза, латинские названия —
по-русски. Слова не меняются; это проверяется тестом на всех четырёх волнах.
Замер на Qwen3-TTS: точка между вариантами даёт шесть ровных пауз по 0,3–0,5 с
и самое живое движение высоты из четырёх вариантов пунктуации.

**Чистка v2** (`socmon/voice/clean.py`): чуткий порог тишины и запас 220 мс
перед речью — вдох перед длинной фразой остаётся; края заливаются комнатным
тоном −60 дБ вместо цифрового нуля — в трубке абсолютная тишина звучит
как обрыв линии.

**Проверка распознаванием** (`socmon voice qa`): каждый файл, включая дубли,
распознаётся Whisper и сверяется по словам; провалившийся дубль убирается
из библиотеки, чтобы подача не сыграла его в живом звонке. Если не прошёл
основной файл и заменить нечем — реплика помечается для пересинтеза.

Сборка на Mac:

```bash
uv run socmon voice realistic --out /tmp/voice-human \
  --model-path …/models/base --references …/references --cache …/cache \
  --takes 3 --temperature 0.8 --room-tone -60
uv run socmon voice qa --media /tmp/voice-human/anna --whisper …/models/whisper --prune
uv run socmon voice qa --media /tmp/voice-human/alex --whisper …/models/whisper --prune --gender m
```

Рантайм и демо играют подачу одинаково: `CallRuntime` получает каталог
и манифест библиотеки, `DemoStudio` — те же. Без каталога поведение прежнее.
Отклик, для которого в библиотеке нет записи, молча пропускается; вопрос
анкеты играет всегда — его отсутствие ловит проверка готовности.

Что подача не делает и не может: она не делает голос неотличимым
от человека. Вступление по-прежнему сообщает, что говорит голосовой
помощник, — это требование ТЗ §8.4, и его никто не отменял.

## Ударения и помехи — прослушивание 09.09.2026

Владелец прослушал сборку с подачей: неверные ударения, плохая
разборчивость, помехи. Разбор по цифрам.

**Помехи — наши.** Пол шума в новых файлах −60 дБ против −76…−109 у сборки
8 сентября: это «комнатный тон», добавленный ради «живости». В начале
коротких реплик — шум на −23 дБ: чуткая обрезка ради «вдоха» сохранила
не вдох, а мусор модели перед речью. Обе опции выключены по умолчанию,
стенд возвращён на сборку 8 сентября.

**Ударения — модели, и на этой модели не чинятся.** Проверка на минимальных
парах (за́мок/замо́к, му́ка/мука́, о́рган/орга́н, а́тлас/атла́с): Qwen3-TTS
не слушается ни знака акута, ни «+» перед гласной — распознаватель в половине
случаев вообще не находит слово, в остальных пик энергии не следует
за разметкой. Управлять ударением здесь нечем. Ошибки на редких словах —
свойство модели, не голоса.

**Что из этого следует.**

* *Silero v5.5* (Бая, Ксения, Айдар, Евгений на `/voices`) ставит ударения
  по словарю (`put_accent`) и звучит чисто. Тембр менее «человеческий»,
  чем клон, зато без ошибок в словах. Для боевого обзвона сейчас — это
  более безопасный выбор.
* *Живой голос* даст человеческий тембр (см. ЗАПИСЬ-ГОЛОСА.md), но не даст
  ударений на Qwen. Клонировать нужно моделью, которая либо принимает
  разметку ударений, либо имеет русский словарь.
* *Отечественный движок с установкой на свой сервер* (SpeechKit on-prem,
  SaluteSpeech) — словарные ударения, естественные голоса, свой тембр
  из записей. Платно, но в российском контуре и без этих компромиссов.
  Для государственного заказчика это, скорее всего, правильный ответ.

## F5-TTS со словарём ударений — 09.09.2026, вечер

Второй движок клонирования — русская дообучка F5-TTS
(`Misha24-10/F5-TTS_RUSSIAN`, чекпойнт `F5TTS_v1_Base_v2`, обучен на тексте

парах; F5 обучен именно на них.

Проверка 09.09 на референсе владельца: четыре фразы, включая пару
«старый за́мок на горе / дверной замо́к на двери», распознаются Whisper
слово в слово, движение высоты 3–3,8 полутона. Референс — первые 11,8 с
записи, оканчивающиеся паузой: более длинный референс, обрезанный на середине
фразы, просачивался хвостом в начало каждой генерации.

Скорость: на Маке через Metal — около восьми секунд синтеза на секунду речи;
на сервере на процессоре — в шесть раз медленнее. Полная библиотека одним
дублем на Маке — около двух часов. Мастера кэшируются по рецепту.

Сборка (отдельное окружение, торч 2.8 — новее тянет torchcodec без FFmpeg):

```bash
uv venv --python 3.12 ~/.venvs/f5
uv pip install --python ~/.venvs/f5/bin/python -e . scipy onnxruntime f5-tts ruaccent soundfile "torch==2.8.0" "torchaudio==2.8.0"
~/.venvs/f5/bin/python -m socmon voice realistic --engine f5 --voice denis --takes 1 \
  --out /tmp/voice-denis-f5 --model-path <каталог с model_v1.safetensors и vocab.txt> \
  --references <каталог с denis.wav и denis.txt> --cache /tmp/voice-denis-f5/cache
```

На сервере то же окружение стоит в `/opt/socmon/venv-f5`, модель —
в `/opt/socmon/models/f5-ru`; словарь ударений там же. Медленно, но для
переозвучки нескольких новых реплик годится.
