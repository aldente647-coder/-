# Подключение сервера опросов к АТС по SIP

Техническая заявка для администратора АТС, через которую пойдут звонки.

## Что подключаем

Сервер голосового помощника социологического опроса: Asterisk 22 (PJSIP).
Сервер сам инициирует исходящие вызовы через вашу АТС и ведёт разговор.
Входящие на него — только обратные звонки и переводы на ваших операторов.

| | |
|---|---|
| IP сервера | `<внешний IP сервера>` (статический) |
| Протокол | SIP через UDP, порт 5060 |
| Медиа | RTP, порты 20000–30000/UDP |
| Кодеки | G.711 A-law (основной), G.711 µ-law |
| DTMF | RFC 2833 |
| NAT | сервер с белым IP, rport и симметричный RTP включены |

## Что нужно от вас

1. **Способ подключения** — любой из двух:
   - **SIP-транк с регистрацией**: адрес SIP-сервера АТС, логин, пароль;
   - **SIP-транк по IP** без регистрации: адрес вашей АТС; со своей стороны
     разрешите вызовы с `<внешний IP сервера>`.
2. **Адрес АТС**, на который отправлять вызовы (IP или имя, порт).
3. **Разрешить исходящие** с нашего транка на мобильные и городские
   номера Республики через вашего оператора связи.
4. **Номер, который увидит абонент.** Желательно номер организации-инициатора или номер,
   на который можно перезвонить и попасть на линию. Укажите, в каком виде
   передавать его в From / P-Asserted-Identity.
5. **Ограничение одновременных вызовов** на нашем транке. На тесте — 2–5;
   в работе нам нужно до 60–100 в вечернее окно (будни 18:00–20:00,
   выходные 12:00–20:00). Сколько выдержит ваш канал к оператору?
6. **Формат набора номера**: `7XXXXXXXXXX`, `8XXXXXXXXXX`, `+7…`, нужен
   ли префикс выхода.
7. **Межсетевой экран**: пропустить SIP (5060/UDP) и RTP с `<внешний IP сервера>`.
   Если удобнее — поднимем VPN (WireGuard / IPsec) между серверами.
8. **Для переводов на операторов** (позже): номер или очередь операторов
   на вашей АТС, куда сервер будет переводить звонок.
9. **Контакт инженера** на время первого подключения.

## Как проверяем

1. Регистрация / связь: `pjsip show registrations` — статус Registered
   (или OPTIONS-пинг для подключения по IP).
2. Один тестовый звонок на мобильный сотрудника: слышимость в обе стороны,
   определившийся номер, задержка.
3. 5–10 звонков сотрудникам по полной анкете, разбор записей.
4. Только после разбора — согласование объёмов и массового режима.

Ни одного звонка на номера жителей до завершения этапа 3.
