# Тестовый звонок живому человеку

Сервер умеет провести интервью от начала до конца: Asterisk, распознавание,
движок анкеты, озвучка, запись, база. Для звонка наружу нужна одна вещь —
SIP-транк: от облачного оператора связи (быстро, для теста) или от АТС
организации-инициатора (для боевой работы).

## 1. Реквизиты транка

От оператора или администратора АТС нужны:

* адрес SIP-сервера;
* логин и пароль SIP-аккаунта — или подключение по IP без регистрации;
* номер, который увидит абонент (на него должно быть можно перезвонить).

Для облачного оператора: в его кабинете создать SIP-аккаунт и привязать
к нему исходящий номер. Если оператор принимает подключение только по IP —
указать там внешний адрес вашего сервера.

## 2. Подключение

Вписать реквизиты в файл секретов `/etc/socmon/env`:

```
SOCMON_TRUNK_HOST=<адрес SIP-сервера>
SOCMON_TRUNK_USER=<логин>
SOCMON_TRUNK_PASSWORD=<пароль>
```

Разложить конфиги и проверить регистрацию:

```bash
set -a; . /etc/socmon/env; set +a
sudo -E deploy/install-configs.sh && sudo asterisk -rx "pjsip reload"
sudo asterisk -rx "pjsip show registrations"
```

Должно появиться `Registered`. Если `Unregistered` или `Rejected` — неверные
логин и пароль либо оператор ждёт подключение по IP. Для подключения по IP
см. раздел 7 в [ПЕРЕДАЧА-ПРОЕКТА.md](../ПЕРЕДАЧА-ПРОЕКТА.md).

## 3. Звонок

```bash
set -a; . /etc/socmon/env; set +a
uv run socmon calltest 79XXXXXXXXX --from <номер-для-абонента> --voice anna
```

Ваш телефон зазвонит, ответьте — и пройдите интервью голосом. Команда
печатает ход звонка: что распознано, что записано, где робот переспросил.
Запись разговора двумя дорожками и интервью с пометкой «тестовое» остаются
в базе; в массив волны тестовое интервью не попадает.

## Что смотреть в тестовом звонке

Это первая проверка системы на настоящем канале, поэтому проверяем
не «работает ли», а «как именно»:

* **Слышимость и естественность.** Как звучит голос в трубке, а не
  в наушниках: громкость, разборчивость перечислений, паузы.
* **Распознавание.** Отвечайте по-разному: коротко, развёрнуто, с «ну»
  и «наверное», перебивайте на середине вопроса, помолчите шесть секунд,
  скажите «повторите», «какие варианты», «не понял», «а вы кто такие».
  Сценарии нестандартных ответов — в `tests/scenarios.yaml`; в звонке
  прогоните хотя бы десяток из них.
* **Задержки.** Сколько проходит от конца вашего ответа до отклика робота.
  Больше секунды — смотреть на распознавание; меньше трёхсот миллисекунд —
  робот будет перебивать.
* **Запись.** После звонка — две дорожки в кабинете, интервью с пометкой
  «тестовое», шкала времени с событиями.

Вывод `calltest` сохраните целиком — по нему видно, где распознавание
ошиблось и что подправить в грамматиках.
